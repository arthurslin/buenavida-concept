# Buena Vida — website concept (private preview)

A password-protected concept redesign for Buena Vida Specialty Coffee. **Not the official store.**

Every page here is encrypted (AES-256-GCM, key derived from the password with PBKDF2-SHA256, 310,000 rounds). The page text, scripts and photos are only readable after entering the password in the browser. The password itself is not stored in this repository.

Pages: `index.html` (home), `quiz.html` (coffee quiz), `learn.html` (Coffee 101), `sol-naciente.html` (product page).

Hosted with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
